# M-Cycle Evaporative Cooling System Design & Optimization

## 📌 Project Overview
An advanced indirect evaporative cooling technology based on the Maisotsenko Cycle (M-Cycle). This system cools incoming air close to its dew-point temperature without adding moisture to the supplied indoor air, providing high thermodynamic efficiency.

---

## 🛠️ Software & Technical Stack
* **CAD Modeling:** SolidWorks / Autodesk Fusion 360
* **Thermal Analysis & Simulation:** ANSYS Workbench
* **Data Computation:** MATLAB / MS Excel

---

## ⚙️ Key Technical Features & Impact
* Designed a counter-flow heat and mass exchanger (HMX) matrix.
* Achieved energy consumption reduction compared to conventional air conditioning systems.
* Optimized air flow distribution and structural rigidity via FEA and thermal simulations.
